# Башня Сингулярности — новая реализация уровня 41

Полная замена схемы из повторяющихся этажей. Основная кампания 1–40 остаётся прежней. В новой башне восемь независимых нижних залов и четыре верхних, связанных различными зависимостями. Один исходный физический компаньон, без чекпоинтов; перезапуск сбрасывает все машины.

У каждого зала собственное правило: связанные азимуты мостов; нагруженный док и возврат источника нагрузки сверху; отражённый портальный луч; сохранение жидкости 8/5/3; запись настоящего движения и одновременное присутствие эха; свободный груз в магнитном поле вокруг экрана; инерционная трансмиссия; расходуемый заряд и пространственный короткий путь; перестановка архивных перегородок; портал на движущейся каретке; полёт из энергии падения; подъём в направленном поле.

Пространство находится внутри общего несущего здания: основание 236 × 252 игровых единицы, подземный технический объём и вершина на высоте 72. Разные верхние залы расположены на отметках 14, 27, 42 и 55. Нижние залы соединены обходными галереями. Большой размер сам по себе не доказывает интересность или длительность оптимального решения.

Архитектура и механизмы: `LabSingularityKit`, `LabSingularityLayout`, `LabSingularityLevel`. Общие строительные примитивы используются повторно, но генератора повторяющихся головоломок нет. `LabSingularityJourney` управляет обычными перемещениями, взаимодействиями, прыжками и выстрелами; он не назначает координаты акторов или состояние задач. `singularity-browser.mjs` отдельно различает архитектурный осмотр камерой и действительное непрерывное прохождение. Результаты осмотра нельзя выдавать за прохождение.

Это рабочая ветка новой версии. Фактический статус проверки, длительность и видео определяются отчётами соответствующего GitHub Actions run и точным коммитом; старые записи башни не являются доказательством для этой реализации.
