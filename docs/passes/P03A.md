# P03A — connected suspension and counterweight clearance

Base: published `91ea2ff95107e6dcc4dc5b847795b5af0dccd50b`, exact imported tree `fb619fc486a73305eab9623c5ead076699cba1b4`. Master spec sections 6, 9, 11; incremental plan P03. One mechanism-art increment, not a new layout and not completion of P03/W03.

## Reproduced defect

The original single counterweight intersects the inclined cassette backing in 28 of 121 sampled poses: cassette heights 7.5–10.2 m. The original two short rope branches have no depicted return attachment to the counterweight. This is a visual/construction defect, not a claim about a new gameplay exploit.

## Change

Replace that visual suspension only: two split side ballast stacks, guide shoes, underslung carriage attachments, bearing-mounted differential drums and connected drive/return cables. The retained visual ballast travel ratio 0.78 is represented by 0.50/0.39 m drum radii. Return guides route the cable away from the inclined backing. A rendered rope stretches only by its changing free length; its lower end remains at its attachment and its upper end at a real drum/guide tangent. No texture or source GLB is added or changed.

The existing actuator remains a **kinematic approximation**, NOT a new force/energy simulation. Height endpoints, actuator speed, gravity, brake logic, cargo support, ray blockers, camera blockers, collision bodies, portal frame/impulse, win rules and saved data stay unchanged. The stronger P07V01 side return and P02 load indicators remain. P01 is still a separate pending package.

Editable factory: `src/game/LabPocketSuspension.js`; explicit parameters: `SUSPENSION`. 16 draw meshes, 8,376 triangles, 3 shared material references, 0 textures. Fixed details are batched by material; four rope meshes share geometry. This increases mechanism detail; it is NOT claimed as a measured performance improvement. The normal room lifecycle disposes generated resources. The runtime factory is the delivered source, not a separately validated GLB.

## Tests / evidence

Eight local targeted tests pass: finite/bounded geometry, rope endpoints and drum tangencies across 121 poses, 0.78 travel/rotation in both directions, idempotent pause/rejected input, 241 sampled backing-vs-ballast clearance poses, protected portal/collision registries, reset and disposal. The first version still intersected the backing; ballast and return cable were moved into the side pockets before acceptance of these tests. No overlap assertion was removed. An initial test also used `width` instead of the actual `halfWidth` frame property and was corrected.

Separate immutable baseline/candidate full-route comparison, complete code tests and native browser review are required. Their execution results must be recorded in the PR; this document does not turn a workflow definition into successful evidence.

`p03-suspension.yml` records both exact versions. Video is a **labelled cutaway inspection of actual game geometry**, with casing omitted from the inspection scene and explicit visual poses at retained 3.5 m/s. It is neither a complete gameplay video nor a physical simulation/hardware benchmark. 1280×720, 30 encoded fps, silent. A normal unmodified start view is retained separately; regular full-campaign CI still checks actual WebGL gameplay.
