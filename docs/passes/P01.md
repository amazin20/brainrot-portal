## Изменение
Только 21-я комната. Существующий контекст возле доступного пульта показывает текущие тормоз/нагрузку и следующее действие. Полное объяснение последовательности решения убрано из этого контекста. Состояния читаются непосредственно при запросе, удерживаемый/висящий груз не считается нагрузкой. Одно E вызывает один `switch`, а не два.

Нет новых геометрий, материалов, ассетов, коллайдеров, событий, таймеров или постоянных интерфейсных блоков. Геометрия, привод, портал, скорость, камера, исходные GLB и сохранения неизменны. Это не выполнение P02 — видимой передачи нагрузки.

## Проверка до/после
Настоящий класс игры в локальном Node-стенде: до — неизменная подпись и два switch-вызова; после — текущая подпись и один switch. Прямая установка позиции применяется только в обозначенном узком стенде взаимодействия; она не выдаётся за прохождение.

Новый локальный набор `node --test tests/lab-pocket-feedback.test.js`: 11/11.
Полная `npm run check` запущена отдельно; итог нужно брать из конкретного журнала, не из этой записи.
Браузерный workflow `P01 brake feedback before and after` проходит к пульту обычным маршрутом и проверяет настоящий E, четыре состояния и native-кадры. Базовая версия специально сохраняется для сравнения; её два вызова ожидаемы. Успех workflow требуется отдельно.
