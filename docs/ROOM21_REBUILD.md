B. Independently send the original free cargo from the low lip through the freight mouth into the structural metal tray. Its actual contact/load retracts the first cross-shaft guard. A then B and B then A are supported. The old 'scout-first' debug alias now runs physical source preparation, not mere sightseeing.

C. The new white inclined face is seen from the service side. Prepare that new direction while hands are free. Retrieve the same cargo down the far-side service stair. Removing it restores the guard; its weight is not mysteriously kept behind.

D. Return with the original cargo through the lower court. The retained source bridge allows the same high well to be reused without sacrificing the final portal pair. The second flight reaches a separate north-east dock at y20. Winning still tests actual joint grounded arrival, not flags A/B/C/D.

The labels above explain dependencies; they are not runtime progress flags. Drive/pawl state is an explicit reduced electromechanical composition of existing airflow, turbine and slider primitives, not a full multibody spring/cam simulation.

Existing character GLBs and all room1–20 source files are unchanged.
