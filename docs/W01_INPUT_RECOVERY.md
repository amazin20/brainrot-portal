# W01 — восстановление ввода: первый отдельный пакет

Дата: 13 сентября 2026 года.
База: `1ee48a5383db71227773e54bfce92e1d7ff1cf32` (v36, 20 комнат).
Исходный blob `InputController.js`: `481188feef9616b023b3ca1f7df843be925cb31b`.

## Что изменено

В `InputController` добавлен сброс клавиш, сенсорного движения, захваченного указателя и очередей прыжка/перезапуска/паузы при потере фокуса или скрытии вкладки. Потеря pointer capture сбрасывает только принадлежащий джойстику указатель. Второй указатель больше не перехватывает активный джойстик. Контрол с нулевой шириной не создаёт NaN в движении. Добавлены явные методы `reset()` и `dispose()`; dispose удаляет обработчики самого контроллера.

Нормализация движения, скорость героя, параметры прыжка, физика порталов, уровни 1–20, персонажи, сохранения и номер версии не изменены. Внешний вид игры не изменяется. Это не полная доработка камеры/анимаций и не реализация уровня 21.

## Воспроизведение и локальная проверка

Среда: Node.js v22.16.0. Исходный файл восстановлен побайтно: `git hash-object` совпал с исходным blob GitHub.

Команда: `node --test tests/input-focus-recovery.test.js`.

Один и тот же набор из 12 проверок: на исходном контроллере 4 проходят, 8 падают; на исправленном проходят 12 из 12. Часть проверок исходной версии падает из-за отсутствия новых reset/dispose API — это не утверждение о восьми независимых игровых дефектах. Дополнительно `node --check src/game/InputController.js` прошёл успешно.

Проверяется действительное тело контроллера в изоляции: DOM, pointer capture и THREE.Vector2 представлены явными тестовыми двойниками. Это не запуск браузера, не проверка WebGL, не плейтест и не аппаратный замер.

## Что остаётся открытым

Полный npm run check, маршруты 1–20, настоящий браузер/сенсорный экран и сравнительное видео в этой локальной среде не выполнены. Прямой git clone не прошёл из-за недоступного DNS github.com; исходники прочитаны через подключение GitHub. Сам факт отправки изменений или создания PR не означает прохождение CI.

Сброс при всех видах внутриигровой/рекламной паузы и вызов dispose из жизненного цикла самой игры требуют отдельной интеграции и проверок; этот пакет обрабатывает фокус/видимость/захват, а не все причины паузы.

W00 завершён только в части сверки исходной main. W01 выполнен частично, с локальной проверкой ввода; визуальная и аппаратная приёмка открыты. W02 и W03 (уровень 21) этим пакетом не реализованы. Публиковать вместо принятой v36 до полной регрессии нельзя.
