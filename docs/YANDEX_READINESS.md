# Яндекс Игры: проверенный пакет и оставшаяся приёмка

Проверено 5 октября 2026 года для исходника `3e0205ebe41804f71eab6792e5d220795fc1028e`,
51-комнатного кандидата `v50-expedition`, CI `37237965678`. Этот документ описывает инженерную проверку,
а не полученное разрешение на публикацию или гарантию модерации.

## Официальная основа

В [требованиях](https://yandex.ru/dev/games/doc/ru/concepts/requirements), обновлённых
29 сентября 2026 года, предел 100 МБ относится к **распакованным файлам**.
В [черновике](https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft) требуется
ZIP с `index.html` в корне и именами без пробелов и кириллицы.
Проверка проекта консервативно ограничивает и ZIP, и распакованные файлы
**100 000 000 байтами**. Отдельный официальный предел сжатого ZIP не утверждается.

SDK для загруженного архива подключается через `/sdk.js`; этот файл предоставляет
платформа и его **нет в ZIP**. Загрузка скрипта и `YaGames.init()` предшествуют
остальным обращениям к SDK. См. [подключение](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about).

[LoadingAPI.ready](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events)
вызывается после подготовки управляемой сцены и меню. Разметка GameplayAPI
в этой игре используется: `start` соответствует настоящей игре, `stop` — меню,
паузе, рекламе и прерыванию страницы. Автоматическая стартовая реклама
обрабатывается [SDK pause/resume событиями](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events).

Для мобильных и планшетов первая явная кнопка «Играть» вызывает
`sdk.screen.fullscreen.request()` до ожидания загрузки комнаты. Отказ браузера
не блокирует игру и не создаёт бесконечную загрузку. Десктоп автоматически
не переводится в fullscreen. [API fullscreen](https://yandex.ru/dev/games/doc/ru/sdk/sdk-params).
Настоящий fullscreen в размещении Яндекса ещё требуется проверить.

Реклама вызывается только SDK, при переходах между комнатами или редком явном
рестарте. Для рестарта сохраняется пятиминутный cooldown. Rewarded-интерфейс
отсутствует в обычной игре по требованиям проекта; соответствующий сервисный
метод проверен отдельно. Он выдаёт награду только по `onRewarded`, однократно;
закрытие, ошибка и timeout не являются наградой.
[Рекламный API](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv).

## Что изменено

- Яндекс-сборка при отказе SDK показывает существующий экран ошибки с повторной
  загрузкой. Она не переходит в бесплатный demo и не объявляет SDK готовым.
- Неудачная загрузка SDK очищает таймер и обработчики скрипта; повтор разрешён.
- Ready отмечается только после реального вызова SDK. Ошибка GameplayAPI
  сохраняется в `lastGameplayError`, не выдаётся за успешную разметку и не мешает
  приложению выключить звук при паузе.
- Рекламная блокировка сохраняется до закрытия открывшейся рекламы, даже если
  рекламный pre-open watchdog уже не действует. Поздние callbacks не получают
  награды и не снимают блокировку другого запроса. Dispose отменяет незавершённые
  запросы и удаляет подписки.
- Фокус, видимость, ручная пауза, SDK и реклама имеют независимые причины блокировки.
  SDK resume не отменяет ручную паузу или скрытие страницы.
- В `yandex` режиме отключена диагностическая ветка загрузки автоматических
  прохождений. В game-only HTML удалена ссылка на отсутствующую видеогалерею.
- Публичные изображения, SVG и аудио копируются только при ссылке из исходников;
  импортированные Vite ресурсы включаются обычной сборкой. Текстуры GLB остаются
  внутри моделей. Обзорные картинки и концепты не включаются.

## Язык и сохранения

`resolvePlatformLanguage(sdk)` читает `environment.i18n.lang` на запуске,
даже при единственном языке. `portalLanguage` сохраняет обнаруженный язык,
`activeLanguage` обозначает настоящий язык интерфейса и комнат.
**Пакет содержит только русский перевод**, в черновике заявлять только русский.
`document.documentElement.lang` остаётся `ru`; английские тексты не имитируются.
Проверены RU, EN и другие неподдерживаемые значения SDK.

[Требование автоопределения](https://yandex.ru/dev/games/doc/ru/requirements/2/14)
допускает один язык, но требует SDK-определение. Обработка неподдерживаемого языка
русским содержимым является решением проекта; отдельной гарантии модерации
этого fallback официальная страница не даёт. Полная английская локализация
остаётся отдельной будущей задачей, а не выполненным свойством этого ZIP.

Прогресс завершённых комнат, выбранная следующая комната и настройки сохраняются
локально сразу после соответствующего действия. Авторизация не запрашивается,
гостевая игра доступна. Внутреннее состояние башни не превращается в чекпоинт.
[Правило сохранений](https://yandex.ru/dev/games/doc/ru/requirements/1/9) допускает
локальное хранение; облако обязательно при инап-покупках. В игре покупок нет,
облачная синхронизация не реализована и не должна отмечаться в черновике.
Отключённое браузерное хранилище позволяет играть в сессии, но не гарантирует
сохранность прогресса после закрытия страницы.

## Воспроизводимые проверки

```bash
node --test tests/lab-v8-platform.test.js tests/lab-page-lifecycle.test.js tests/lab-localization.test.js
node scripts/check-yandex-platform.mjs
npm run build:yandex
CHROME_PATH=/path/to/chrome node scripts/check-yandex-browser.mjs
node scripts/package-yandex.mjs
```

`package-yandex.mjs --build` сначала собирает пакет. Аргументы `--input=`,
`--output=` и `--report=` позволяют выбрать каталоги. По умолчанию результат:
`artifacts/brainrot-portal-yandex.zip`, отчёт `qa/yandex-package.json`.

Проверка архива подтверждает:

- Корневой `index.html`, безопасные имена, CRC ZIP и оба ограничения размера.
- Зависимости **всех 51 уровней** основной кампании и хеш каждого GLB.
- Действующий бюджет 14 GLB менее 4 MB; компактный манифест и три Draco decoder файла.
- Наличие статических ресурсов HTML/CSS/import, относительные пути игры.
- Отсутствие MP4, галерей, QA, исходных моделей, review-модулей и sourcemaps.
- SHA-256 ZIP и каждого файла, исходный commit и признак изменения tracked-файлов.
  Генерируемые untracked QA/артефакты не делают исходники «изменёнными»; отдельный
  хеш всех build inputs включает и новые игровые исходники. Их
  изменение во время сборки/упаковки прекращает проверку. `builtFromCurrentSource`
  истинно только с `--build`; упаковка старого каталога не выдаётся за новую сборку.

Browser check открывает production ZIP-содержимое из **вложенного URL**, заменяя
только `/sdk.js` контролируемым SDK mock. Проверяет SDK отказ, ready/start/stop,
SDK язык, настоящий AudioContext при паузе, рекламу с прерыванием фокуса,
сохранение выбранной комнаты после reload, мобильный fullscreen вызов и
отсутствие debug/видеогалереи. Отчёт и кадры: `qa/yandex-browser/`.

Программный WebGL и SDK mock **не подтверждают** FPS устройства, реальную
рекламную доставку, выплаты или весь процесс модерации.

## Перед отправкой

После интеграции остальных игровых изменений заново выполнить сборку,
browser check и ZIP-проверку. Предыдущий архив не объявлять финальной версией.
Открыть финальный архив в черновике Яндекса: проверить настоящий SDK, рекламу,
сохранения после reload/смены ориентации, fullscreen, звук при сворачивании,
доступность управления и полезную длительность игры на заявленных устройствах.
Также нужны реальные Safari/Android проверки и промоматериалы, соответствующие
этому пакету. Заявлять только проверенные платформы и существующие переводы.
