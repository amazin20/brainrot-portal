# Текущая GitHub-демка: постоянное обновление

28 октября 2026 пользователь явно отменил прежний запрет на публикацию **GitHub-демки** и потребовал объединить накопленные улучшения и обновлять её при дальнейшей работе. Это не разрешение автоматически публиковать игру в Яндекс Играх.

## Единственная линия текущей демки

Источник всей игры и меню: `upgrade/tz-completion-20261023`. Не собирать публичную игру из старого `main` и не подменять новые главы отдельными картинками. Основной адрес остаётся `https://amazin20.github.io/brainrot-portal/campaign-v67/`; корень сайта и короткий адрес `/demo/` направляют на него. Постоянные индексы и пространство сохранений v67 не меняются ради публикации.

`Build current GitHub demo` запускается на каждом push рабочей ветки. Он устанавливает зафиксированные зависимости, проверяет сохранения, доступ к комнатам и Atlas, собирает весь текущий исходник и выполняет native WebGL smoke. В smoke отдельно проверяется загрузка ремастеров «Биосферы», «Оптики» и замка. На экране меню показаны реальная дата сборки и короткий SHA.

Только успешный завершённый build запускает `Publish current GitHub demo` из main. Публикация принимает артефакты только своего репозитория, указанной ветки и последнего SHA; устаревший прогон не может откатить демку. Существующие версии и видео восстанавливаются по хешам, предыдущая активная v67 сохраняется в архиве, новая сборка записывается в активный адрес. Перед deployment повторно проверяются ветка и состояние сайта. После deployment проверяются все новые байты по HTTP и выполняется запуск именно публичной игры.

После полностью успешной публикации `Show current demo version in README` обновляет верхний блок README настоящей датой и ссылкой на поставленный исходник. Исторические даты ниже не выдаются за дату обновления текущей демки.

## Границы проверки

Это автоматическая доставка рабочей демоверсии, не обход или подмена полного набора игровых регрессий. Неудачные общие тесты остаются открытыми. Метаданные содержат `verified:false`, `fullCampaignAccepted:false` и `yandexPublished:false`. Нельзя приравнивать smoke-запуск шести случаев к прохождению всех 51 комнат, человеческому плейтесту или измерению на телефоне.

Сломанная сборка не заменяет существующую демку. Нельзя удалять проверки ради публикации. Подробный текущий штамп: `/demo-publication.json`; точная игровая версия: `/campaign-v67/build-info.json`.

Воспроизведение защитных тестов публикации: `python3 -m unittest discover -s tests -p test_current_demo_publisher.py`.
