## Реальные результаты маршрутов

Новая сборка завершила четыре браузерных прохождения: обычный перенос и отдельная перевозка спутника, каждый при 1280×720 и 390×844. Оригинальные объекты и физические тела сохранены, сбросов и возрождений нет.

Старая сборка прошла два широких маршрута. Оба прежних портретных маршрута упёрлись выстрелом в настоящий настил. Поэтому исходные два сравнительных задания остаются красными, а их отчёты `pass:false` сохранены без исправления. Это ошибка автоматического пути, не доказательство непроходимости уровня человеком. В новом пути используется существующий нижний этаж и та же пара порталов.
