# БРЕЙНРОТ ПОРТАЛ — v24

Существующий репозиторий переименован: `amazin20/brainrot-portal`. Публичное название игры и проекта — **БРЕЙНРОТ ПОРТАЛ**, имя пакета — `brainrot-portal`. Диагностические API с прежним префиксом остаются совместимыми; настройки и прогресс комнат 1–11 мигрируют автоматически.

## Состав ревизии

- Планировки комнат 1–11 сохранены. Прежние комнаты 12–20 удалены из активной кампании вместе с их реализациями.
- Новая комната 12 «Обратная перспектива»: большой единый атриум, изменение точки наблюдения, самостоятельный перелёт физического спутника и перенаправление накопленной скорости игрока. Терминалов и цепочки переключателей нет.
- Камера после переноса пол → стена восстанавливает выбранный игроком наклон. Прицел можно опустить почти вертикально вниз; мышь и сенсорное управление используют одинаковые пределы.
- К видеорегрессиям добавлен прыжок с быстрым поворотом возле портала. Новая комната записывается в обычном прохождении, без подстановки положения игрока или постановочной камеры.

Описание пространственных решений и границ проверки: [REVERSE_PERSPECTIVE_V24.md](docs/REVERSE_PERSPECTIVE_V24.md).

## Проверка и публикация

Для этой ревизии обязательны семь параллельных заданий CI: все исходные тесты и пакет, физические маршруты, три группы WebGL-комнат, реальный ввод и портальная камера, видеорегрессии и контракт SDK. Публикация использует артефакт той же ревизии; публичная проверка сравнивает полный SHA, байты активных моделей, обычное прохождение комнаты 12 и возврат кампании к комнате 1.

Этот документ описывает требования к ревизии и не заменяет результат CI. Факт публикации определяется завершённым GitHub Actions и публичным `build-info.json`. Старые отчёты v21–v23 не подтверждают v24.

## Границы результата

10–15 минут первого самостоятельного решения — цель дизайна, а не измеренное время. Маршрут, заранее знающий решение, проверяет исполнимость и не измеряет сложность для человека. Проверки обходов конечны. Контракт SDK проверяется с заглушкой, а не настоящими рекламными показами; CI не подтверждает FPS на пользовательском GPU. Полное исходное ТЗ по всем будущим уровням и анимациям этим проходом не объявляется завершённым.
