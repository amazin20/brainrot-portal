`npm run package:yandex` создаёт `artifacts/brainrot-portal-yandex.zip`: 21 файл, 14 активных GLB и вся кампания. Проверенный CI-пакет v48 занимает 3 986 095 байт в ZIP и 5 978 833 байта после распаковки, значительно меньше ограничения 100 МБ. Видео, галерея, QA-модули и отладочные маршруты в пакет не входят. SDK загружается с `/sdk.js`, который предоставляет площадка.

Готовность пакета, гостевые сохранения, пауза/звук/реклама, язык, сенсорное управление и границы проверки описаны в [YANDEX_READINESS.md](docs/YANDEX_READINESS.md). Реальный черновик Яндекса, физические устройства и модерация проверяются отдельно. Пакет содержит русский язык.

## Управление

WASD — движение; мышь — обзор; Space — прыжок; ЛКМ/ПКМ — порталы; E — взять или отпустить спутника, использовать механизм; Esc — пауза. На телефоне доступны экранные кнопки. Портальная пушка используется при свободных руках.

Основной вход и `?level=N` выбирают `foundation`. Архивные `?edition=classic` и `?edition=open` остаются отдельными редакциями с отдельными сохранениями.
