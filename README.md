# БРЕЙНРОТ ПОРТАЛ

Браузерная 3D-головоломка от третьего лица: одна пара порталов, физика и живой спутник. Основная редакция `foundation` содержит 41 испытание.

**[Играть](https://amazin20.github.io/brainrot-portal/)** · **[Складчатый замок — уровень 41](https://amazin20.github.io/brainrot-portal/?edition=foundation&level=41)** · **[Галерея прохождений](https://amazin20.github.io/brainrot-portal/walkthroughs.html)**

## Кампания v48

Полностью заменены комнаты 18, 20, 31, 32, 33, 34, 35, 36, 37, 39 и 40. Новые задачи используют электрическую цепь, портальный трос, грузовую рейку, оптическую тень, обратную пружину, пневмоаккумулятор, возврат через два запора, ударный ротор, магнитный канал, тепловую память и согласование апертур. Закрыты обнаруженные обходы 14, 16, 32, 35 и двух секций замка. Сохранения изменённых комнат сбрасываются выборочно; остальные результаты и настройки сохраняются.

Уровень 41 полностью заменён **Складчатым замком**. Один атриум связывает пять высот: 0, 18, 36, 54 и 72 м. Одиннадцать разных механизмов соединены галереями, лестницами и зависимостями. Исходный брейнрот доставляется через грузовые порталы, приводит настоящие контакты и противовесы, возвращается после использования и участвует в финале. Верхние залы пересекают общий объём; сложность пространственной схемы поддержана разными материалами крыльев, приборами, видимыми запорами и указателями источников. Архитектура оригинальная.

Закрыты обнаруженные физические обходы: второй прыжок за счёт старого coyote-time, проезд через отключённую исходную стену, выход сквозь тонкую стену на большой скорости, перенос за границу меньшей апертуры, прохождение человека через грузовую щель, выступающие углы вращающегося куба и проход через непортальные перегородки. Объекты сохраняют реальную форму, ориентацию, импульс и идентичность. Исправлено отпускание груза внутри портального горла и закрытие прохода под ним. Двадцать три движущиеся детали в комнатах 31/32/33/34/39 сохраняются в сцене и совпадают со своими коллизиями; термометр использует отдельный материал.

## Яндекс Игры

`npm run package:yandex` создаёт `artifacts/brainrot-portal-yandex.zip`: 21 файл, 14 активных GLB и вся кампания. Проверенный CI-пакет v48 занимает 3 986 095 байт в ZIP и 5 978 833 байта после распаковки, значительно меньше ограничения 100 МБ. Видео, галерея, QA-модули и отладочные маршруты в пакет не входят. SDK загружается с `/sdk.js`, который предоставляет площадка.

Готовность пакета, гостевые сохранения, пауза/звук/реклама, язык, сенсорное управление и границы проверки описаны в [YANDEX_READINESS.md](docs/YANDEX_READINESS.md). Реальный черновик Яндекса, физические устройства и модерация проверяются отдельно. Пакет содержит русский язык.

## Управление

WASD — движение; мышь — обзор; Space — прыжок; ЛКМ/ПКМ — порталы; E — взять или отпустить спутника, использовать механизм; Esc — пауза. На телефоне доступны экранные кнопки. Портальная пушка используется при свободных руках.

Основной вход и `?level=N` выбирают `foundation`. Архивные `?edition=classic` и `?edition=open` остаются отдельными редакциями с отдельными сохранениями.

```sh
npm ci
npm run dev
npm test
npm run build
npm run check:yandex-platform
npm run package:yandex

```

Матрица обычных, альтернативных и восстановительных маршрутов: `node scripts/qa-campaign-routes.mjs --edition=foundation`. Восемь групп дополнительных атак проверяются через `qa-speedrun-core-new.mjs`, `qa-speedrun-early-new.mjs`, `qa-speedrun-middle-new.mjs`, `qa-speedrun-late-new.mjs` и `qa-speedrun-castle-new.mjs`. Конечные быстрые атаки: `qa-adversarial-core.mjs`, `qa-adversarial-early.mjs`, `qa-adversarial-late.mjs` и `qa-adversarial-castle-independent.mjs` в каталоге `scripts`. Исторические материалы и регрессии сохранены в Git; прежние контракты заменённых механизмов обновлены под их новую физическую задачу.
