## Управление

WASD — движение; мышь — обзор; Space — прыжок; ЛКМ/ПКМ — порталы; E — взять или отпустить спутника, использовать механизм; Esc — пауза. На телефоне доступны экранные кнопки. Портальная пушка используется при свободных руках.

Основной вход и `?level=N` выбирают `foundation`. Архивные `?edition=classic` и `?edition=open` остаются отдельными редакциями с отдельными сохранениями.
