# БРЕЙНРОТ ПОРТАЛ

Браузерная 3D-головоломка от третьего лица: одна пара порталов, физика и живой спутник. **Опубликованная демка v50-expedition содержит 51 испытание** в основной редакции `foundation`.

**[Играть в демку](https://amazin20.github.io/brainrot-portal/?v=6f1eec5)** · **[Новые уровни 42–51](https://amazin20.github.io/brainrot-portal/?edition=foundation&level=42&v=6f1eec5)** · **[Складчатый замок — уровень 41](https://amazin20.github.io/brainrot-portal/?edition=foundation&level=41&v=6f1eec5)** · **[Прохождения](https://amazin20.github.io/brainrot-portal/walkthroughs.html)**

## Что вошло в демку

Кампания расширена с 41 до 51 комнаты. Новая глава включает «Разность давлений», «Петлю Фарадея», «Центробежный регулятор», «Центр тяжести», «Настроенный демпфер», «Хрупкий предохранитель», «Клиновый шлюз», «Кривую отражения», «Падающую архитектуру» и «Адресную эстафету».

Выбор уровней оформлен картой шести секторов с карточками, иллюстрацией лаборатории и анимированной загрузкой. В сборку вошли изменения материалов, освещения и анимаций, а также исправления совпадения моделей и коллизий лестницы комнаты 14 и понтона комнаты 28. Исходные модели игрока, спутника, пушки и рюкзака сохранены.

Галерея содержит 51 непрерывную запись актуальных основных маршрутов и четыре дополнительных маршрута комнат 48–51. Старые записи и предыдущая опубликованная игра сохранены отдельно с исходным происхождением. Записи автоматические, 640×360 при 4 кадрах/с; это не измерение FPS игры. Запись замка длится 17:23,25 без перезапусков и контрольных точек.

## Размер и границы готовности

Точные файлы игрового кандидата занимают 6 473 422 байта. Проверенный пакет Яндекс Игр занимает 4 175 342 байта в ZIP и 6 229 484 байта после распаковки. Видео не входят в игровой пакет; галерея и её архивы хранятся отдельно от него.

Это готовая к открытию браузерная демка, а не заявление о выполнении всего master-ТЗ. Человеческая оценка интересности и визуального качества всех комнат, аппаратные FPS/VRAM на физических устройствах и приёмка в настоящем окружении Яндекс Игр остаются отдельными этапами. Конечный набор автоматических атак не доказывает отсутствие всех мыслимых обходов.

## Управление

WASD — движение; мышь — обзор; Space — прыжок; ЛКМ/ПКМ — порталы; E — взять или отпустить спутника и использовать механизм; Esc — пауза. На телефоне используются экранные кнопки. Пушка доступна при свободных руках.

## Работа с игровым исходником

Игровой исходник опубликованной 51-комнатной демки и контроллер публикации — разные коммиты. `main` хранит контроллеры доставки; не следует считать его прежний игровой код источником текущего публичного кандидата. Для воспроизведения демки используйте закреплённый игровой SHA или создайте рабочую ветку от него:

```sh
git fetch origin
git switch --detach 6f1eec54d47fed7916f5346a218525292d15fd62
npm ci
npm run dev
npm test
npm run build
```

`tools/expedition-release.json` закрепляет принятый кандидат, идентификаторы архивов и контрольные суммы. Точный состав публичной демки доступен в [build-info.json](https://amazin20.github.io/brainrot-portal/build-info.json) и [expedition-release.json](https://amazin20.github.io/brainrot-portal/expedition-release.json). Нельзя подменять проверку новой игровой версии повторным использованием старых результатов.
